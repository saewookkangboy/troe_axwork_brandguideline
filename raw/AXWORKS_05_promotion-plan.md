# AX WORKS 온라인 프로모션 플랜 v1.0

**기간** 런칭 후 12주 · **총예산 가설** 1,200만원 (월 400만원)
**단일 전환 목표** 진단 완료 → 리드
**측정 기준** 진단 완료 1건당 CPA. 클릭·노출은 보조 지표.

## 1. 퍼널 설계

```
인지        Instagram Reels · YouTube Shorts · LinkedIn 도달
  ↓
관심        블로그 유입 (검색 + AI 인용) · 카탈로그 다운로드
  ↓
행동        3분 진단 완료          ← 모든 광고의 목표 지점
  ↓
전환        Blueprint 결제 / Academy 문의 / Sprint 상담
  ↓
확장        AX OS · GAEO 구독
```

**핵심 판단**: 이 카테고리에서 "무료 진단"은 리드마그넷 중 전환 마찰이 가장 낮다. 이메일 없이 결과를 볼 수 있다는 점을 **광고 카피에 반드시 노출**한다. 그것 자체가 차별점이다.

**① "예외 로그" 시리즈 — 동영상 15초 · 주력 소재**

브랜드 시그니처를 그대로 광고로. 화면 전체가 Gate Line.

```
0.0–1.5s  파이프라인이 좌→우로 진행. mono 자막: "자동화, 잘 되고 있나요?"
1.5–4.0s  ◇에서 정지. Halt 컬러 점멸.
          EXCEPTION: 캠페인 중도 변경
4.0–7.0s  예외 3개가 순차 등장 — 지표 결측 / 권한 만료 / 기준일 불일치
7.0–11.0s "데모에서는 완벽했습니다."
          "실무에서는 첫 주에 멈췄습니다."
11.0–15.0s "어려운 건 처리가 아니라 검증입니다."
          [3분 진단 · 이메일 없이 결과 확인]
```
- 음악 없음, 자막만. 무음 시청 환경에서 오히려 강함
- 세로(9:16) 우선, 1:1 파생
- **왜 되는가**: 대부분의 AI 광고가 "가능성"을 보여줄 때 혼자 "실패 장면"을 보여준다. 스크롤을 멈추는 건 후자다.

---

**② "숫자 카드" 시리즈 — 정적 이미지 4종**

```
[Ink 배경 · mono 초대형]
   88%
   AI 에이전트 파일럿이
   프로덕션에 도달하지 못합니다
   ─────────────
   Forrester · Anaconda 2026
```
변형: `67% vs 33%` (벤더 주도 vs 내부 구축) / `21%` (거버넌스 성숙 조직) / `5.1개월` (중간 회수기간)

- 제작 원가 최저, 테스트 회전 빠름. 초기 학습용 물량 담당
- 출처 표기가 신뢰 장치이자 GEO 자산 (스크린샷 인용 시 출처 동반)

---

**③ "Builder Level 사다리" — 캐러셀 5장**

B0→B4를 한 장씩. 마지막 장 CTA: `당신은 어디입니까 — 개인 진단 3분`
- 커리어 불안을 자극하지 않으면서 자기 위치 확인 욕구를 건드림
- 저장·공유율이 가장 높을 소재. 오가닉 확산 병행 기대

---

**④ "환급 계산기" — 정적 + 동영상 10초 · Academy 캠페인 전용**

```
800만원 교육 → 실제 부담 40만원
사업주 직업능력개발훈련 환급
우선지원대상기업 90% · AI 융합형 수도권 외 95%
[우리 회사 환급률 계산하기]
```
- **가장 높은 CTR이 예상되는 소재.** 가격 장벽 제거가 직접 소구
- 주의: 환급률은 기업 조건에 따라 다름 → "조건에 따라 상이" 고지 필수

---

**⑤ "만들어주지 않습니다" — 동영상 20초 · 브랜드 소재**

화면에 문장이 타이핑되다가 취소선이 그어짐.
```
"AI 자동화, 만들어 드립니다"   ← 취소선
"만들 수 있게 합니다"          ← Gate 컬러 강조
```
+ 워크숍 현장 실사 3컷 (연출 없음, 화면·손·화이트보드)

| 항목 | 설정 |
|---|---|
| 형식 | **Document Ads**(리드폼) 주력 + Single Image 보조 |
| 문서 소재 | `Builder Level B0~B4 기준표` 8p PDF / `주간 리포트 에이전트가 죽는 5가지 예외` 6p |

## 9. 측정 체계

**필수 이벤트** `diagnose_start` `step_complete[1-4]` `capability_gap_view` `quote_view` `refund_calc_use` `lead_submit` `payment_complete`

**UTM 거버넌스**
```
utm_source   = meta | naver | google | linkedin | kakao | newsletter
utm_medium   = cpc | cpm | video | doc | organic | email
utm_campaign = axw_launch | axw_academy1 | axw_geo
utm_content  = 소재코드 (예: exlog15_9x16_v2)
utm_term     = 키워드 (검색광고만)
```
소재코드 규칙: `[컨셉][길이]_[비율]_[버전]` — 리포팅 자동 분해 가능하게.

**주간 리뷰 지표**
CPA(진단 완료) / 진단 완료율 / 진단→견적 조회율 / 소재별 3초 시청률 / 채널별 리드 품질(상담 전환율)

**12주 목표**
| 지표 | 목표 |
|---|---|
| 진단 완료 | 500건 |
| 평균 CPA | 24,000원 |
| Blueprint 결제 | 20건 |
| Academy 1기 등록 | 12명 |
| Sprint 90 계약 | 3건 |
| 광고 기여 매출 | 8,000만원+ |

> **중단 기준**: 4주 시점 CPA 45,000원 초과 채널은 예산을 승자 채널로 이관한다. 소재가 아니라 채널 문제일 수 있으므로 소재 2세대까지는 유지하고 판단한다.
