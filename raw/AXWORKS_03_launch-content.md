## 3. 블로그 (troe.kr/journal → axworks.kr/journal) — GEO 인용 자산

**목표** LinkedIn은 사람이 읽고, 블로그는 **AI가 읽는다.** 인용 가능한 구조가 최우선.

### 3.1 작성 규칙 (GAEO 자가 적용)

1. 첫 단락에 **한 줄 정의 블록**을 둔다. AI가 그대로 인용할 형태.
2. H2·H3를 **질문형**으로 쓴다.
3. 모든 수치에 **기관 + 연도**를 붙인다.
4. "업계 1위 / 압도적" 같은 자기 평가 문장을 쓰지 않는다. 객관 정보가 없으면 인용되지 않는다.
5. 표·목록으로 구조화한다. 긴 문단만 이어지면 AI가 핵심을 추출하지 못한다.
6. 작성자(박충효), 근거 자료, 경험을 명시한다 — E-E-A-T.
7. `.md` 버전을 병행 제공하고 `/llms.txt`에 등재한다.

### 4.1 콘텐츠 포맷 5종

**① 예외 카드 (주력 · 캐러셀 6장)**
```
1p  이 에이전트는 첫 주에 죽습니다        [Ink 배경 · Display]
2p  주간 성과 리포트 자동화              [파이프라인 다이어그램]
3p  예외 01 — 지표 결측                  [Halt 컬러 카드]
4p  예외 02 — 캠페인 중도 변경
5p  예외 03 — 계정 권한 만료
6p  예외를 먼저 꺼내는 것이 설계입니다
    → 카탈로그 전체 보기 (프로필 링크)
```

**② Builder Level 사다리 (교육형 · 캐러셀 7장)**
B0~B4를 한 장씩. 마지막 장에 "당신은 어디입니까 — 개인 진단 3분".
저장률이 가장 높을 포맷. 커리어 관심 유발.

**③ 용어 정의 (1장 · 시리즈)**

## 5. 채널 간 연결 규칙

```
Instagram  →  인지·저장          → 프로필 링크 → 진단
LinkedIn   →  신뢰·리드          → 첫 댓글 링크 → 진단 / Academy 문의
Blog       →  검색·AI 인용       → 본문 CTA    → 진단 / 카탈로그 다운로드
                                              ↓
                                        진단 결과 = 견적
                                              ↓
                              Blueprint · Sprint 90 · Academy
```

**원칙**
- **모든 채널의 1차 CTA는 진단 하나.** 채널마다 다른 전환점을 두면 측정이 무너진다.
- 블로그 글 1편 = LinkedIn 1편 + Instagram 캐러셀 1개로 반드시 3분할 (제작 효율).
- 콘텐츠는 전부 **Agent Catalog에서 나온다.** 카탈로그 15종이 곧 6개월치 콘텐츠 원본이다.
