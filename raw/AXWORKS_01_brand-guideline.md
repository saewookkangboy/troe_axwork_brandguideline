## 1. 브랜드 전략

### 1.1 왜 새 브랜드가 필요한가

TROE는 20년 업력의 **자문 브랜드**다. 신뢰는 크지만 "무엇을 사는지"가 없다. 반대로 신규 서비스는 기간·산출물·가격이 명확한 **실행 상품**이다. 두 성격을 한 이름에 담으면 둘 다 흐려진다.

→ **엔도스먼트 구조**: `AX WORKS by TROE`
TROE는 신뢰의 출처(who vouches), AX WORKS는 구매 대상(what you buy).

### 1.2 네이밍

**채택: AX WORKS**

| 근거 | 설명 |
|---|---|
| Works = 작동한다 | 브랜드 핵심 명제 "작동하는 것만 남는다"와 직결 |
| Works = 작업장·공장 | 만들어주는 곳이 아니라 **같이 만드는 작업장** |
| Works = 저작·성과물 | 산출물 중심 상품 구조와 일치 |
| AX | 이미 시장에 형성된 카테고리 용어. 검색·인용 유리 |
| 확장성 | AX Works Academy / Sprint / Catalog / Suite로 자연 확장 |

**대안 (기록용)**
- *BUILDLINE* — 라인 모티프는 좋으나 제조업 연상, 마케팅팀 타겟과 거리
- *만드는 사람들* — 정서적 호소력은 크나 B2B 임원 보고 자료에서 힘이 약함

**표기 규칙**
- 정식: `AX WORKS` (전부 대문자, 사이 공백 1)
- 국문 병기: `AX 웍스` — 필요 시에만. 본문은 영문 표기 유지
- 금지: AXWorks, Ax Works, AX-WORKS, 액스웍스

### 1.3 포지셔닝 스테이트먼트

> **AI 도입을 고민하는 마케팅·PR 팀에게**
> AX WORKS는 **업무 1개를 90일 안에 실제로 가동시키고, 그 과정을 팀이 직접 할 수 있게 만드는 AX 실행 브랜드**입니다.

> 근거는 21년의 마케팅 현장 경험과, 검증·예외처리를 먼저 다루는 방법론입니다.

### 1.4 브랜드 코어 아이디어

# 작동하는 것만 남는다

파일럿의 88%가 프로덕션에 못 간다. 남는 건 데모가 아니라 **매일 돌아가는 것** 하나뿐이다.
이 문장은 슬로건이자 KPI다 — 가동률.

### 1.7 카피 원칙

1. **숫자 앞에 형용사를 두지 않는다.** "획기적인 절감" ✕ / "주당 6시간, 절감률 65%" ○
2. **동사는 능동, 주어는 고객.** "AI가 혁신합니다" ✕ / "팀이 직접 만듭니다" ○
3. **실패 조건을 먼저 쓴다.** 예외 케이스를 보여주는 것이 이 브랜드의 신뢰 장치다.
4. **출처를 붙인다.** 인용 수치에는 기관·연도. GEO 인용 확률도 함께 올라간다.
5. **문장을 짧게.** 임원 A4 1장 보고 체계가 브랜드 자산이다. 랜딩 카피도 같은 규율.

## 2. 비주얼 아이덴티티

### 2.1 디자인 컨셉 — "운영 콘솔과 명세서"

이 브랜드의 세계에는 광택이 없다. 있는 것은 **파이프라인, 승인 게이트, 예외 로그, 검증 리포트**다.
따라서 비주얼은 SF적 미래감이 아니라 **스펙 시트와 운영 화면**의 언어를 쓴다.
글로우·그라디언트 배경·추상 3D 렌더는 전면 금지.

### 2.2 시그니처 — Gate Line (게이트 라인)

브랜드를 기억하게 만드는 단 하나의 요소.

```
수집 ──── 정규화 ──── 초안 ──◇── 발행
                            ▲
                       사람 승인
```

- 가로선 = 에이전트가 처리하는 구간
- **◇ 마름모 = 사람이 판단하는 승인 지점**
- 예외 발생 시 라인은 ◇에서 멈춘다

이 도형이 로고 마크이자, 섹션 구분자이자, 슬라이드 목차 표식이자, 광고 크리에이티브의 뼈대다.
**"승인 지점 없는 자동화는 우리 브랜드가 아니다"** 를 시각으로 선언한다.

### 2.3 로고

**워드마크**
```
◇ AX WORKS
```
- 마크(◇)와 워드마크 사이 간격 = 대문자 X의 폭
- 워드마크는 IBM Plex Sans SemiBold, 자간 +0.08em
- 엔도스먼트는 워드마크 하단, 헤어라인 1px 위, mono 10px: `BY TROE`

**최소 크기** 디지털 가로 96px / 인쇄 24mm
**보호 영역** 사방으로 마름모 1개 크기
**금지** 마름모 회전·채움 변경, 워드마크 자간 임의 변경, 그림자·외곽선·그라디언트, 사진 위 직접 배치(반드시 단색 판 위)

**컬러 운용**
| 배경 | 로고 |
|---|---|
| Paper | Ink 워드마크 + Signal 마름모 |
| Ink | Paper 워드마크 + Gate 마름모 |
| 단색 인쇄 | 100% 단색 |

### 2.4 컬러 시스템 — 의미가 곧 팔레트

**색이 장식이 아니라 상태를 뜻한다.** 제품 다이어그램·슬라이드·광고에서 동일 규칙을 적용한다.

```css
:root {
  /* Base */
  --ink:      #0C1116;  /* 본문 텍스트 · 다크 섹션 배경 */
  --slate:    #3A4551;  /* 보조 텍스트 */
  --line:     #D6DBE0;  /* 헤어라인 */
  --paper:    #F4F6F8;  /* 기본 배경 */
  --white:    #FFFFFF;

  /* Semantic — 브랜드의 핵심 */
  --signal:   #1C51B9;  /* 에이전트가 실행하는 구간 (TROE 브랜드 블루 계승) */
  --gate:     #C8912B;  /* 사람이 판단하는 승인 지점 */
  --verify:   #0E7C66;  /* 검증 통과 · 가동 중 */
  --halt:     #B3261E;  /* 중단 · 예외 · 자동화 금지 */
}
```

| 토큰 | HEX | 의미 | 사용 비중 |
|---|---|---|---|
| Ink | `#0C1116` | 기본 텍스트, 히어로 배경 | 30% |
| Paper | `#F4F6F8` | 지배 배경 | 45% |
| Signal | `#1C51B9` | 에이전트 실행, 주 CTA | 12% |
| Gate | `#C8912B` | 사람 승인, 강조 | 8% |
| Verify | `#0E7C66` | 검증·성과 수치 | 3% |
| Halt | `#B3261E` | 예외·경고 | 2% |

**규칙**
- Gate와 Halt를 장식으로 쓰지 않는다. 뜻이 있을 때만 등장.
- 한 화면에 Signal·Gate·Verify·Halt가 모두 나오는 곳은 **파이프라인 다이어그램 하나뿐**.
- 그라디언트 금지. 단, Ink→#12181F 5% 이내의 수직 미세 변화는 허용.
- 접근성: Paper 위 Signal 대비비 6.1:1, Ink 위 Gate 6.8:1 — 본문 사용 가능.

### 2.5 타이포그래피

| 역할 | 서체 | 용도 |
|---|---|---|
| **Display (KR)** | Pretendard 800 | 헤드라인. 자간 -0.03em, 행간 1.15 |
| **Display (EN)** | IBM Plex Sans SemiBold | 로고·영문 제목. 자간 +0.06em |
| **Body** | Pretendard 400 / 500 | 본문. 행간 1.75, 최대 폭 68자 |
| **Utility** | **IBM Plex Mono 500** | 라벨·수치·코드·섹션 표식·예외 코드 |

> **Mono가 이 브랜드의 성격을 나른다.** 눈썹 라벨, 지표, 스프린트 번호, 예외 케이스 코드는 전부 mono 대문자 + 자간 +0.12em. 스펙 시트의 목소리를 만든다.

**타입 스케일 (rem)**
```
Display XL  3.75  / 800 / -0.03em   히어로
Display L   2.50  / 800 / -0.025em  섹션 헤드
Title       1.50  / 700 / -0.02em   카드 제목
Body L      1.125 / 400 / 1.75      리드 문단
Body        1.00  / 400 / 1.75      본문
Label       0.75  / 500 / +0.12em   mono, 대문자
```
모바일에서 Display XL → 2.25rem, Display L → 1.75rem.

**한글 조판 규칙**
- 제목은 **의미 단위로 줄바꿈**(`<br>` 수동). 자동 줄바꿈으로 어절이 잘리지 않게.
- 숫자·영문은 mono 또는 Plex Sans, 국문은 Pretendard — 혼용 시 baseline 정렬 확인.
- 줄임표는 `…`, 붙임표는 `·` 사용. 이모지 금지(광고 크리에이티브 예외).

### 2.6 레이아웃

- **좌측 레일 컬럼**(폭 120px)에 mono 섹션 코드를 세로로 배치. 스펙 문서의 인상.
- 본문 최대 폭 1180px, 콘텐츠 컬럼 760px.
- **모서리 반경 2px.** 거의 각지되 완전한 0은 아님.
- 그림자 금지. 층위는 1px 헤어라인과 배경 명도차로만 표현.
- 섹션 간 구분선은 실선이 아니라 **Gate Line 모티프**(가로선 + 중앙 ◇).

### 2.7 번호 체계

**순서가 정보인 곳에만 번호를 쓴다.**
- 사용 O: `B0→B4` 빌더 레벨 / `S1·S2·S3` 90일 스프린트 / `W1…W8` 8주 커리큘럼 / `L1→L5` 조직 성숙도
- 사용 X: 서비스 특징 나열, 장점 3가지 — 여기엔 라벨을 쓴다

### 2.8 이미지·다이어그램

- **사진 사용 최소화.** 스톡 이미지(악수·회의실·홀로그램 뇌) 전면 금지 — 현재 troe.kr의 언스플래시 이미지가 대표적 개선 대상.
- 허용: 실제 작업 산출물의 스크린샷·문서 캡처, 워크숍 현장 사진(연출 없음).
- 기본 시각 언어는 **다이어그램**: 파이프라인, 승인 지점, 예외 분기, 검증 대조표.
- 다이어그램 규칙: 선 1.5px, 노드는 사각(에이전트) / 마름모(사람) / 원(데이터).

### 2.9 모션

- 기본은 정지. 움직이는 것은 **Gate Line 하나**.
- 히어로: 파이프라인이 좌→우로 진행하다 ◇에서 정지 → `EXCEPTION` 라벨 노출 → 승인 후 재개. 1회 재생 후 정지.
- `prefers-reduced-motion` 존중, 전환은 160ms `cubic-bezier(.2,.6,.2,1)`.
- 패럴랙스·자동 캐러셀·타이핑 효과 금지(히어로 예외 로그 1회 제외).
