## 1. 사이트의 단일 목적

> **3분 진단을 시작하게 만든다.**

부차 목적: Blueprint 결제 · Academy 문의 · GAEO 가입. 하지만 **모든 페이지의 1차 CTA는 진단으로 통일**한다. 진단이 곧 리드이고, 역량 갭 산출(F-14)까지 붙으면 진단 결과가 곧 견적이기 때문이다.

**핵심 설계 판단**: 랜딩과 진단을 분리하지 않는다. 현재 ax.allrounder.im이 진단만 고립돼 있는 것이 최대 손실이다. 신규 사이트는 **랜딩 → 진단 → 견적 → 결제**를 한 도메인에서 끝낸다.

`LABEL: 왜 멈추는가`

| 이관 | 만들어준 사람이 떠나면 멈춘다 | MIT NANDA: 벤더 주도 67% vs 내부 33% |

## 6. GEO·SEO·AEO 설계

**자사 방법론(GAEO)을 자사 사이트에 먼저 적용한다.** 이것이 GAEO 제품의 최고 레퍼런스다.

### 구조화 데이터
| 페이지 | 스키마 |
|---|---|
| 전체 | `Organization` + `sameAs`(troe.kr, park.allrounder.im, LinkedIn, GitHub) |
| 상품 | `Service` + `offers` (가격 밴드 포함) |
| Academy | `Course` + `EducationalOccupationalCredential` |
| 레벨 기준표 | `DefinedTermSet` — B0~B4를 정의된 용어집으로 |
| 저널 | `Article` + `author`(Person: 박충효) |
| FAQ | `FAQPage` |
| 케이스 | `CaseStudy`(Article) |

### AI 인용을 노린 콘텐츠 구조
- 모든 핵심 페이지 상단에 **`한 줄 정의` 블록** — AI가 그대로 인용할 수 있는 형태
  예: `Builder Level(B0~B4)은 비개발자가 AI 에이전트를 명세·조립·검증·운영하는 역량을 5단계로 정의한 프레임워크다.`
- 수치에는 **기관·연도 병기**. 출처 없는 주장은 인용되지 않는다.
- 제목 계층(H2/H3)을 질문형으로: `B1 명세자는 무엇을 할 수 있어야 하는가?`
- `/llms.txt` 배치 + 주요 페이지 Markdown 버전(`.md`) 병행 제공 — 에이전트 크롤러 대응

### 타깃 쿼리 (한국어)
`AX 전환 진단` · `마케팅 AI 에이전트 구축` · `비개발자 AI 에이전트 교육` · `AI 파일럿 실패 이유` · `AI 교육 고용보험 환급` · `GEO 최적화 대행` · `AI 도입 컨설팅 비용`

### 성과 지표
`AICS`(정의 프롬프트 세트 내 브랜드 인용률) 월간 추적 — GAEO 제품으로 자사를 측정하고 그 결과를 공개.

## 7. 기술 스택 · 개발 계획

| 항목 | 선택 | 근거 |
|---|---|---|
| 프레임워크 | Next.js (App Router) + TypeScript | GAEO Analysis가 이미 Next.js. 팀 일관성 |
| 배포 | Vercel | 기존 gaeoanalysis 배포 경험 |
| 스타일 | Tailwind + CSS 변수(브랜드 토큰) | 토큰 시트 그대로 이식 |
| 진단 상태 | localStorage(14일) → 계정 도입 시 DB | 기존 구현 승계 |
| 폼·리드 | 초기 Google Forms 유지 → 2차에 자체 API | 빠른 런칭 우선 |
| 결제 | 토스페이먼츠 또는 아임포트 (Blueprint 전용) | 소액·단건 |
| 분석 | GA4 + Microsoft Clarity + 자체 이벤트 | 진단 단계별 이탈 측정이 핵심 |
| CMS | MDX 파일 기반 (저널·카탈로그) | 개발자 1인 운영 전제 |

**개발 우선순위**
- **Phase 1 (2주)** — 랜딩 + 진단 v2(F-01·F-02·F-14) + Sprint 90/Academy 상세. 결제 없음
- **Phase 2 (2주)** — 자동 견적(F-03), PDF 리포트(F-04), 환급 계산기(F-16), 카탈로그 5종
- **Phase 3 (4주)** — 계정·재진단 추적(F-06), 결제(F-10), 인증 레지스트리(F-17), GAEO SSO

`diagnose_start` · `step_complete[1~4]` · `capability_gap_view` · `quote_view` · `sku_card_click` · `refund_calc_use` · `lead_submit` · `payment_complete`

## 8. 품질 기준

- 모바일 우선. 진단 폼은 한 화면에 한 질문.
- LCP 2.0s 이하, CLS 0.1 이하.
- 키보드 포커스 가시화, `prefers-reduced-motion` 존중, 대비비 AA.
- 진단 이탈 시 14일 복구 (기존 구현 유지) + 이메일 없이 결과 확인 원칙 고수.
