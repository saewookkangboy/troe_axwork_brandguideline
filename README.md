## 가이드라인 구성 (10개 섹션)

### 01 · Brand Strategy — 브랜드 전략
왜 TROE와 이름을 나누는지, 네이밍·포지셔닝·슬로건·보이스·카피 원칙, 오디언스 매트릭스, 경쟁 맵, 메시지 아키텍처, Evidence Library까지 브랜드의 말과 근거를 정의합니다.

### 02 · Visual Identity — 비주얼 아이덴티티
Gate Line 시그니처, 로고 락업, 컬러 토큰, 타이포(Pretendard / IBM Plex Sans·Mono), 레이아웃·번호·도형 문법(사각=에이전트, 마름모=사람, 원=데이터), 모션 규칙을 정합니다.

### 03 · Sub-brand Architecture — 서브 브랜드 아키텍처
AX WORKS 뒤에 동사·산출물 이름을 붙이는 네이밍 규칙과 TROE(모브랜드)·서비스 브랜드 관계를 정리합니다. GAEO는 인지도 유지를 위한 예외입니다.

### 04 · Brand Package Portfolio — 브랜드 패키지 실물
Gate Line 다이어그램 키트, PPTX 마스터(14종), 소셜·문서 템플릿, 명함·이메일 서명·제안서 표지, 인증 배지, W5 예외 케이스 워크숍 키트 등 제작물 포트폴리오입니다.

### 05 · Digital System — 디지털 시스템
4px 스페이싱, radius·elevation(그림자 없음), 버튼·칩·인풋·테이블 등 UI 키트, 아이코노그래피, 데이터 시각화, Diagnose / Blueprint / Operate 화면 적용 규칙을 담습니다.

### 06 · Content & Channel — 콘텐츠·채널 템플릿
영문 사이트(axworks.im/en), LinkedIn·Instagram 정형 포맷, 블로그 이미지·네임태그 배너 규격. **수치로 시작 → 예외를 보여줌 → CTA 하나** 원칙을 채널별로 구체화합니다.

### 07 · Brand Experience — 브랜드 경험
고객 여정 터치포인트별로 “여기서 보여야 할 것”과, 고객 앞에 서는 사람이 지켜야 할 행동 원칙을 정의합니다.

### 08 · Responsible AI — 책임 있는 AI
리스크 커뮤니케이션 원칙, 사고 시 대응 문구, 절대 쓰지 않는 약속형 표현(“이런 조건에서는 멈춥니다”로 대체)을 미리 정해 둡니다.

### 09 · Governance — 운영 규범
로고 오용 사례, 파일 네이밍, 접근성, 소유·승인 절차, 공동 브랜딩, **브랜드 KPI(가동률 우선)** 등 가이드라인이 실제로 지켜지게 만드는 규칙입니다.

## 핵심 시각·카피 규칙 (요약)

- **색은 꾸밈이 아니라 상태** — Paper / Ink / Signal / Gate / Verify / Halt 토큰을 제품·슬라이드·광고에 동일하게 적용
- **모션은 기본 OFF** — 예외는 Gate Line 커버 애니메이션뿐 (`prefers-reduced-motion` 존중)
- **스톡 이미지 금지** — 악수·회의실·홀로그램 뇌 등; 타이포와 Gate Line 키트로 대체
- **대외 수치는 Evidence Library에 있는 것만** 사용
